# SPIDERWEB — live read-only mirror

**PAPER TRADING ONLY — simulated money.** A memecoin paper-trading dashboard: a team of bots
(scanner, rug-check, momentum, sniper, risk) votes on memecoins using free public data
(Binance public klines, DexScreener). Fees and slippage are counted on every simulated trade.

This repo is an automated snapshot (front end + sanitised state JSON), refreshed about once a minute.
No keys, no accounts, no wallets, no real orders. Not financial advice.

Live page: https://cliwireee.github.io/spiderweb-live/
